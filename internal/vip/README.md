# VIP 模块维护说明

本模块承载隐藏彩蛋，相关实现说明保留在模块目录中，不在项目首页 README 中介绍。

`vip.json` 位于应用数据目录，与 `session.json` 同目录，缓存当前账号的每日领取和升级成功记录。

本地缺少当天领取记录或升级前，应用会通过 SDK 的 `YouthMonthVipRecord` 查询服务端，同步官方 App 等其它设备的操作，并将确认的成功记录写入 `vip.json`。

查询成功缓存 30 秒，失败后冷却 1 分钟。查询缓存按账号和北京时间日期隔离；领取或升级请求发出后会清除查询缓存。查询失败或响应无法识别时，不会直接发送相应的领取或升级请求。
